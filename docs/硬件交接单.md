## 三、接线规范

### 3.1 供电母线

```
5V/2A 适配器 ──┬── 面包板红轨 (+) ──┬── 模块① VCC
               │                   ├── 模块② VCC
               │                   └── 模块③ VCC
               │
               └── 面包板蓝轨 (-) ──┬── 模块① GND
                                   ├── 模块② GND
                                   ├── 模块③ GND
                                   └── ESP32  GND   ← 共地，必须
```

> **ESP32 单独用 USB 供电**（不接 5V 母线），只把它的 `GND` 接到蓝轨。

### 3.2 驱动模块接线（三路做法完全相同）

| 驱动模块引脚 | 接到 |
|--------------|------|
| `VCC`（电源正） | 面包板**红轨** |
| `GND`（电源负） | 面包板**蓝轨** |
| `SIG`（信号） | ESP32 对应 GPIO（25 / 26 / 27） |
| `OUT+` | 负载 一根线 |
| `OUT-` | 负载 另一根线 |

> 丝印可能写作 `+5V / GND / IN(PWM) / OUT+ / OUT-`，**以实物丝印为准**。

**负载接线**

- **蠕动泵**：红线 → `OUT+`，黑线 → `OUT-`（接反则反转，不是故障）
- **电磁阀**：两根线**不分正负**，任意接 `OUT+` / `OUT-`

### 3.3 共地 —— 最容易漏的一步

用万用表**通断档**确认以下每一条都「导通」：

- [ ] ESP32 `GND` ↔ 面包板蓝轨
- [ ] 模块① `GND` ↔ 面包板蓝轨
- [ ] 模块② `GND` ↔ 面包板蓝轨
- [ ] 模块③ `GND` ↔ 面包板蓝轨
- [ ] 5V 适配器负极 ↔ 面包板蓝轨

> **缺共地 → 现象是"有电但不动"或动作错乱**，排查故障时先查这一条。

## 四、安全约束（要写进固件）

| 约束 | 数值 | 原因 |
|------|------|------|
| 阀单次最长通电 | **≤ 30 s** | 阀额定 4.5V，用 5V 驱动，长通电线圈发烫 |
| 泵不得长时间空转 | 空载 ≤ 数秒 | 干转磨损软管 |
| GPIO 不得直驱负载 | — | GPIO 仅约 20 mA，负载 200~500 mA，直连会烧芯片 |
| 上电前必查共地 | — | 见 3.3 |
| 上电默认态 | 泵停、阀关 | 常闭阀断电即安全位 |

## 五、测试代码

### 5.1 单路最小验证（循环泵）

```cpp
// 测试：循环泵 转3秒 / 停3秒（高电平触发）
#define PUMP_PIN 25

void setup() {
  pinMode(PUMP_PIN, OUTPUT);
  digitalWrite(PUMP_PIN, LOW);   // 先关，防止一上电就转
  delay(2000);
}

void loop() {
  digitalWrite(PUMP_PIN, HIGH);  // 泵转3秒
  delay(3000);
  digitalWrite(PUMP_PIN, LOW);   // 停3秒
  delay(3000);
}
```

**合格标准**：泵「转 3 秒 → 停 3 秒」不断循环。

### 5.2 三路联动（泵 + 两个阀）

```cpp
// 1泵 + 2阀 联动测试
// 触发方式：高电平触发
// 接线：泵→GPIO25，切换阀→GPIO26，排废阀→GPIO27

#define PUMP_PIN    25
#define VALVE_A_PIN 26   // 切换阀
#define VALVE_B_PIN 27   // 排废阀

#define PUMP_ON_MS    10000UL   // 泵运行 10 秒
#define VALVE_ON_MS     5000UL   // 阀开 5 秒
#define VALVE_LIMIT_MS 30000UL   // 阀最长通电保护 30 秒

// 带超时保护的开阀函数
void valveOn(int pin, unsigned long ms, const char* name) {
  Serial.print("    ");
  Serial.print(name);
  Serial.println(" ON");
  digitalWrite(pin, HIGH);
  unsigned long t0 = millis();
  while (millis() - t0 < ms) {
    if (millis() - t0 > VALVE_LIMIT_MS) {   // 双保险
      Serial.println("    ! 阀超时保护触发");
      break;
    }
    delay(10);
  }
  digitalWrite(pin, LOW);
  Serial.print("    ");
  Serial.print(name);
  Serial.println(" OFF");
}

void setup() {
  Serial.begin(115200);
  pinMode(PUMP_PIN, OUTPUT);
  pinMode(VALVE_A_PIN, OUTPUT);
  pinMode(VALVE_B_PIN, OUTPUT);

  // 上电先全部关闭（安全态）
  digitalWrite(PUMP_PIN, LOW);
  digitalWrite(VALVE_A_PIN, LOW);
  digitalWrite(VALVE_B_PIN, LOW);

  delay(2000);
  Serial.println("=== 1泵 + 2阀 联动测试启动 ===");
}

void loop() {
  Serial.println("[1] 循环泵 ON");
  digitalWrite(PUMP_PIN, HIGH);
  delay(PUMP_ON_MS);
  digitalWrite(PUMP_PIN, LOW);
  Serial.println("    循环泵 OFF");
  delay(3000);

  Serial.println("[2] 切换阀");
  valveOn(VALVE_A_PIN, VALVE_ON_MS, "切换阀");
  delay(3000);

  Serial.println("[3] 排废阀");
  valveOn(VALVE_B_PIN, VALVE_ON_MS, "排废阀");

  Serial.println("[4] 本轮结束，5秒后下一轮\n");
  delay(5000);
}
```

## 七、故障排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 泵/阀完全不动 | **共地没接** | 查 ESP32 `GND` ↔ 蓝轨 |
| 一上电就动作 | 触发极性判断反 | 代码里 `HIGH` / `LOW` 互换 |
| 阀一直吸着不放 | 程序逻辑未关闭 | 检查代码；加 30 s 超时保护 |
| 阀发烫 | 通电过久 | 加最长通电限制 |
| ESP32 动作时重启 | 电源带不动 | 确认 5V/2A；泵阀勿同时长时间开 |
| 串口乱码 | 波特率不对 | 串口监视器设 115200 |
| 泵转向相反 | 接线方向 | 把泵两根输出管对调即可，不必改电路 |
