# 面向连续细胞代谢监测的低成本智能电化学微流控系统——实验创新性分析报告（v3.0）

> 报告用途：用于向老师汇报本实验的创新性（可据此改造为 PPT 或开题材料）
> 版本说明：v3.0 根据评审意见重构——创新点收敛到三个"工程难题型"点；芯片改为"培养 + 检测解耦、下腔闭环回路、停流-校准协议"，支撑 12~72 h 连续监测；生物内容压缩为最小验证场景；软件侧引入 AIoT 远程监控。

## 一、实验概述

**实验名称**：面向连续细胞代谢监测的低成本智能电化学微流控系统

**实验目标**：设计并验证一套"**膜隔离静置培养 + 下腔闭环微循环 + 独立电极检测模块 + AIoT 远程监控**"的细胞代谢连续监测系统。以乳酸 / 葡萄糖为模型指标，解决现有电化学细胞代谢监测"**测不久、测得漂、离不开人**"的三个工程难题，实现 12~72 h 连续、定量、可无人值守的代谢动态监测，并用于加药刺激下的代谢响应评估。

**核心技术路线**：

```
培养芯片（膜上静置培养，细胞不扰动）
      ↓  代谢物经膜扩散进入下腔
下腔闭环微循环（与检测模块联机，同成分培养基）
      ↓
测量协议：循环均质 → 停流平衡 → 静测 →（每6h）在线自校准
      ↓
恒电位仪采集 → 漂移补偿与数据质量评估 → 12~72h 连续曲线
      ↓
AIoT：远程监控 / 告警 / 自动报告   （应用：代谢动态研究 / 药物响应评估）
```

**本版相对 v2 的关键调整（对应一轮评审意见）**：

| 评审意见 | 本版响应 |
|---------|---------|
| 商品化电极、原位检测不算创新点 | 二者降级为"工程特性"（低成本、可复现的底气），不再单独立点 |
| 第 4 点过于空洞 | 删除"仿生 / 可扩展"画饼叙事；创新收敛为三个各钉一个具体难题的点 |
| 芯片需考虑连续检测 | 结构重构为"培养 + 检测解耦 + 下腔闭环 + 停流平衡静测 + 在线自校准"，并新增无细胞 72 h 长稳验证（V1）作为实证 |
| 过多侧重生物、应发挥专业优势 | 生物只作为被测对象与验证场景（V1/V2 最小实验）；仿生屏障、3D 培养、跨膜吸收等生物叙事全部移除 |
| 软件加入 AIOT | AIoT 数据链列为创新点三，系统架构含远程监控 / 告警 / 自动报告 |

## 二、背景与问题提出

### 2.1 为什么关注细胞代谢（背景，从简）

细胞能量代谢是细胞状态的最直接反映：肿瘤细胞糖酵解增强导致葡萄糖消耗加快、乳酸分泌上升。**代谢分子的动态变化**是细胞功能改变的前哨信号，可作为药物评估与代谢研究的实时指标。

### 2.2 为什么用微流控 + 电化学（平台选择，从简）

- **微流控/培养芯片**：为细胞提供可控、可复现的培养微环境，将培养与检测集成于一体。
- **电化学检测**：灵敏度高、响应快、成本低，可原位获取动态电流信号。
- 二者结合的意义：以低成本的工程化手段做**长时间代谢动态监测**。

### 2.3 问题聚焦：电化学细胞代谢监测的三大工程难题

现有"电化学 + 细胞代谢"方案要真正服务 12~72 h 连续监测，普遍卡在三个**工程问题**上：

1. **测不久**：静态检测腔或"细胞贴着电极"的构型下，检测依赖被动扩散，电极表面持续富集/消耗、产物堆积致"电极中毒"，难以长时间连续运行；
2. **测得漂**：酶电极活性随时间衰减、参比电位漂移、温度/基质变化，不做在线校准则长时间定量失效；
3. **离不开人**：换液、校准、盯数据、出报告都要人值守，实验者无法离开现场，也难以及时发现断流、气泡、漂移等异常。

> **判断**：谁能用**低成本、可复现的工程手段**同时解决"久、准、无人值守"三点，谁就真正创造了价值。这正是本项目立足点，也契合物联网专业"传感 + 控制 + 数据"的能力结构。

## 三、现有研究综述（文献调研）

从"能否长时间连续、能否无人值守、系统是否闭环"三个新维度重新审视 4 篇代表性工作：

### 3.1 姚春莹：三维生物传感器监测细胞能量代谢

- 三维 PEDOT/CNTs/普鲁士蓝酶电极 + 胶原水凝胶 3D 培养，实时测乳酸/葡萄糖；检测对象分体构建、无微流控芯片。
- **局限（面向连续监测）**：细胞与电极同体，长时间下电极毒性/副产物积累风险高；无自动校准与流控更新机制，长时连续定量未论证。

### 3.2 陈阳：微流控芯片抗真菌药物筛选与代谢产物研究

- 液滴微流控 + 离线 LC-MS 代谢组学。
- **局限**：依赖离线大设备，天然非连续、非实时；平台面向终点分析而非动态跟踪。

### 3.3 孙慧娜：电化学活细胞 NO 释放监测与药物/代糖评估

- 金属卟啉/CuO 复合电极，GelMA 3D 培养，电化学实时测 NO。
- **局限**：单指标、培养与传感系统集成度有限；电极定制；长时间连续与自动校准未涉及。

### 3.4 于志航：液滴微流控单细胞分析关键技术

- 液滴封装 + 化学发光，侧重分选/裂解/单细胞异质性。
- **局限**：面向单点/单细胞测量，与"群体细胞长时间连续培养监测"路线不同。

### 3.5 现状总结（更新对比表）

| 维度 | 姚春莹 | 陈阳 | 孙慧娜 | 于志航 | 本项目 |
|------|--------|------|--------|--------|--------|
| 检测对象 | 乳酸+葡萄糖（分体） | 代谢组（离线） | NO（单指标） | 单细胞代谢 | **乳酸+葡萄糖（同体系，可扩展）** |
| 细胞与电极关系 | 细胞长在电极支架上 | 离线取样 | 水凝胶包细胞 | 液滴包裹 | **培养与检测物理解耦（膜隔离 + 独立检测模块）** |
| 实时性 | 实时 | 离线 | 实时 | 实时（单点） | **实时连续（12~72h）** |
| 长时连续/自动校准 | 未论证 | 不适用 | 未论证 | 不适用 | **停流平衡静测 + 在线自校准协议** |
| 无人值守/远程 | 无 | 无 | 无 | 无 | **AIoT 远程监控/告警/自动报告** |
| 电极来源 | 定制 | 定制/质谱 | 定制 | 定制 | **商品化条状电极（工程特性）** |

> **缺口结论**：上述工作各有侧重，但**没有一个以低成本工程手段同时解决"12~72 h 连续定量 + 自动校准 + 无人值守远程监控"**——这正是本实验的立足点。

## 四、本实验的创新点（3 个，各钉一个具体难题）

### 创新点一：膜下腔非侵入采样 + 闭环微循环 + 停流静测（系统级采样/流控方案）

**解决的难题**：静态检测腔或"细胞贴电极"构型导致电化学检测"测不久"——扩散滞后、电极表面富集/中毒，连续 12~72 h 不成立。

**内容**：
- 细胞在膜上**静置贴壁培养**（培养基基本不扰动，贴近常规培养习惯）；
- 代谢物经多孔膜扩散进入膜下**小体积下腔**（芯片独有结构，普通培养芯片没有）；
- 下腔与**独立检测模块**构成闭环微循环：常态下泵以低速循环，负责均质下腔液体、冲洗电极表面、消除局部耗尽与产物堆积；
- 每个测量窗口"**停流**"，让膜上下经短暂平衡后**静测**固定时序电流 → 得到复现性好、几何可比的浓度读数。

**对比超越**：不是"在芯片上集成了一个电极"——而是**膜下腔非侵入采样 + 闭环循环 + 停流静测**这一整套方案。区别于三类现有做法：① 电极直接泡培养液（中毒快、扰细胞）；② 隔一段时间取样到外置池（取样本身扰动细胞，不是连续监测）；③ Seahorse 等商品化仪器（昂贵、封闭式、非芯片叙事）。我们的方案用低成本结构件 + 标准件，让连续监测在**系统层面**成立，而非依赖"测一下算一下"的补救。

### 创新点二：停流静测协议 + 在线自校准闭环（系统级测量协议）

**解决的难题**：酶电极 12~72 h 活性衰减、参比漂移、基质变化导致"测得漂"；人工校准与换液打断连续性。

**内容**：
- 泵 / 阀按**固件状态机**自动执行"循环 → 停流 → 静测 → 校准"循环，无需人值守；
- 周期性（如每 6 h）由三通阀将**已知浓度标准液**切入检测模块进行**在线标定**，自动更新灵敏度/截距；
- 软件对连续读数做**漂移补偿与数据质量评估**（趋势一致性、异常点标记）；
- **关键优势**：校准与换电极都在独立检测模块完成，**全程不触碰细胞腔**——实验不因维护而中断。

**对比超越**：几乎所有"外置电极检测"方案都是**实验前校准一次到底**，长时运行误差累积不可控。我们把"标定"做成系统的**常态化自动环节**——这不是某一个部件的改进，而是"膜下腔采样 + 循环均质 + 停流静测 + 周期校准"整套协议的闭环设计。这正是物联网专业"状态机 + 时序控制 + 信号处理"能力的直接体现。

### 创新点三：端-云 AIoT 数据链——远程监控、智能告警、自动报告（系统级数据链）

**解决的难题**：12~72 h 实验"离不开人"——无人值守时的监控、异常发现、数据整理都依赖人在现场。

**内容**：
- 端侧：恒电位仪采集 →（ESP32 等）本地实时处理与缓存；
- 传输：WiFi/MQTT 上行至网关/云，手机与网页**远程实时查看曲线**；
- 智能告警：断流、气泡、温度越界、信号异常漂移自动推送；
- 数据服务：浓度-时间曲线拼接、加药/换液事件自动打标、代谢速率分段推算、**自动生成报告**并可导出。

**对比超越**：现有电化学细胞代谢系统几乎都是"仪器 + 上位机"单机形态，人必须在实验室守着。我们做成"传感—控制—云端"完整数据链——实验者在实验室外即可全程掌控，数据自动整理、异常自动告警、结束自动出报告。这是系统级方案的"最后一公里"，也是物联网专业最具辨识度的部分。

### 工程特性（非创新点，但支撑可复现性）

- **商品化条状三电极**：即买即用、可随时更换，把电极从"定制科研耗材"降为"标准件"；
- **开源恒电位仪（NanoStat 体系）**：与商品化电极天然兼容，整套检测链低成本；
- 结构件可外协、无需洁净室工艺 → 方案易复现。

## 五、系统设计与工作原理

### 5.1 总体架构（两件套 + 闭环回路）

```
【培养芯片】                       【检测模块】
┌─────────────────┐               ┌─────────────────────┐
│ 培养井（细胞静置）│               │ 电极流道（可插拔）     │
├ 多孔膜 ──────────┤               │  · 商品化条状三电极    │
│ 下腔（小体积）    │ ◄──循环管──►  │    （检测区露于流道底）│
└────┬────────┬───┘    │    ▲      │  · 气泡阱             │
     │入液口  │出液口   │    │      └─────┬─────────┬──────┘
     └────┬───┴────────┘    │              │         │
          └───── 微泵（低速循环同成分培养基） ────────┘
                              ▲
             校准支路：三通阀 ──┴── 标准液瓶（周期切入，校准后排废/自循环）
```

- **循环原则**：下腔 + 检测模块内循环的是**与培养液同成分的培养基（无细胞）**，避免"营养渗漏"式干扰，也不扰动膜上的细胞。

### 5.2 培养芯片（含膜与下腔）

- 上盖/培养井：膜上静置培养，侧壁留加药口、换液口（人工事件，系统自动打标）；
- 多孔膜：聚碳酸酯（PC），孔径约 0.4~3 μm（拦细胞、放小分子代谢物），可更换；
- 下腔：紧贴膜下的小体积腔（建议数十 μL~百 μL），带进/出液口与检测模块闭环。

### 5.3 检测模块

- 电极流道：透明流道，商品化条状三电极自侧槽插入、检测区暴露于流道底，端子外接恒电位仪；
- 泵阀：微型泵 + 三通阀（常态循环 / 校准切入），外置或模块化集成；
- 储液与气泡阱：保证长时间运行无气泡、体积稳定；
- 校准支路：标准液瓶与排废/隔离阀，**校准不回流至细胞腔**。

### 5.4 测量协议（时序，建议值待 V1 标定）

| 阶段 | 动作 | 建议时长/参数 |
|------|------|--------------|
| ① 常态循环 | 泵低速闭环循环（均质下腔、冲洗电极） | 数分钟~数十分钟一档，流速低（建议先试 50~100 μL/min） |
| ② 停流平衡 | 停泵，膜上下跨膜平衡 | 5~15 min（视下腔体积与膜面积） |
| ③ 静测 | 电极固定时序采样 → 得 1 个浓度点 | 30~60 s 短窗安培 |
| ④ 在线校准 | 三通阀切标准液 → 读取标准响应 → 切回冲洗 | 每 6 h 一次，约 3~5 min |

> 一个循环 ≈ 1 个"校正后浓度点"，重复 12~72 h 拼接成连续曲线；换液/加药作为事件标注。

### 5.5 软硬件清单

| 类别 | 组成 |
|------|------|
| 传感 | 商品化条状三电极（酶修饰后测乳酸/葡萄糖） |
| 仪表 | NanoStat 开源恒电位仪（可程控时序）或自制微恒电位仪 |
| 流控 | 微型泵、三通阀、软管接头、气泡阱、储液/标准液瓶 |
| 边缘 | ESP32（采集、状态机、MQTT 上行、缓存） |
| 上位机/数据库 | Qt 桌面或网页端 + SQLite 存储 |
| 云端/远程 | MQTT 代理 / 轻量云，手机端远程查看与告警 |
| 算法 | 停流采样、在线标定更新、漂移补偿、异常检测、速率推算、自动报告 |

### 5.6 工作原理（六步）

1. 组装：培养芯片下腔与检测模块接管闭环，注入同成分培养基；
2. 接种：细胞滴入培养井，膜上贴壁静置培养；
3. 连续监测：按 5.4 协议循环执行，自动产出连续浓度曲线；
4. 在线校准：周期切入标准液更新标定参数（不扰细胞）；
5. 事件实验：加药/换液经人工或预留口执行，系统自动打标并记录响应；
6. 远程与报告：数据上行云端，手机远程监控，结束后自动出报告。

## 七、验证实验方案（生物内容最小化）

### V1 无细胞长稳实验（核心，证明"连续检测成立"）

- **目的**：证明系统能在 12~72 h 内**以分钟级读点自动校准地**给出稳定定量读数，直接回应"长时间连续检测能否成立"。
- **做法**：培养芯片 + 检测模块组装，注入**已知浓度**乳酸/葡萄糖标准液（用培养基配制，消除基质效应）；自动运行完整协议 72 h。
- **指标**：各采样点**回收率**及其随时间的变化；在线校准对回收率的维持作用。
- **通过标准（目标值，可协商）**：校准后单点回收率误差 <15%，且无随时间的单调漂移。

### V2 细胞验证（简版应用走通）

- **目的**：证明系统可用于真实细胞代谢动态监测。
- **做法**：一种代谢活跃、易培养的细胞（如 HepG2/C6，由生物侧确定）膜上静置培养，系统自动记录 12~24 h 乳酸上升/葡萄糖下降曲线；设加药组（代谢抑制剂或化疗药）与对照组，比较代谢响应趋势。
- **通过标准**：加药组与对照组代谢趋势出现**显著差异**即可，不做机制研究。

### V3 系统演示（收尾）

- 手机远程查看实时曲线、收到异常告警、一键导出报告——面向竞赛/汇报演示。
