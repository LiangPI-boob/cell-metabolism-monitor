## 一、项目是什么

**一句话**：做一台能**自动养细胞 + 自动测代谢指标（葡萄糖/乳酸）**的准连续监测系统。

**核心原理**
1. 细胞在多孔膜（PC 0.4μm）上静置培养
2. 代谢物透过膜扩散进「膜下小体积腔」（约 78 μL）
3. 下腔与独立检测模块用软管**闭环循环**
4. 停流静测（安培法）+ 每 6 小时**在线自校准**
5. 覆盖 **12~72 小时无人值守**

**系统架构（双 MCU）**

```
[手机/PC 浏览器] ⇄ WiFi ⇄ [主机 NanoStat (ESP32 + LMP91000)]
                              ├─ 电化学采集
                              ├─ 网页 + WebSocket (端口81)
                              └─ Wi-Fi TCP (NanoStatAP, 192.168.4.1:3333) ⇄ [从机 ESP32 流体控制板]
                                                                 ├─ 循环泵   → GPIO25
                                                                 ├─ 切换阀   → GPIO26
                                                                 └─ 排废阀   → GPIO27
```

### 4.2 从机固件 ✅ 已烧录验证

**文件**：`c:\Users\jie'jie'jie'jie\Desktop\创新性研究\slave_firmware\slave_firmware.ino`（v1.1）

**硬件配置**
| 执行器 | 引脚 | 通道号 |
|---|---|---|
| 循环泵 | GPIO25 | pump ch 0 |
| 切换阀 | GPIO26 | valve ch 0 |
| 排废阀 | GPIO27 | valve ch 1 |
| 接主机 | Wi-Fi TCP（STA → `192.168.4.1:3333`） | — |

**关键实现**
- **双通道**：USB Serial（调试）+ Wi-Fi TCP（接主机）；两个通道都能收命令，响应回到发命令的通道。`Serial2` 仅作台架备用，**非运行链路**
- **驱动模块为高电平触发**（已验证）：`HIGH` = 导通
- **安全保护**：
  - 心跳超时 **120 秒**（主机静测约 60s，留余量）→ 停泵关阀 + 上报，但状态回 IDLE（可直接恢复，不锁死）
  - 阀最长通电 **30 秒**
  - 泵单次最长 1 小时
  - 上电默认：泵停、阀关
- 非阻塞设计（全程 `millis()`）

**JSON 行协议（Wi-Fi TCP 3333 承载；USB 串口调试，115200，8N1）**

命令：
```json
{"cmd":"ping"}
{"id":1,"cmd":"pump","ch":0,"speed":50,"ms":60000}
{"id":2,"cmd":"valve","ch":0,"state":"open"}
{"id":3,"cmd":"stop_all"}
{"id":4,"cmd":"status"}
{"id":5,"cmd":"clear"}
```
响应：`{"id":1,"ok":true}` / `{"id":2,"ok":false,"err":"E_PARAM","msg":"..."}`
事件：`{"evt":"boot",...}` / `{"evt":"fault","code":"E_NO_HEARTBEAT"}` / `{"evt":"hb","state":"IDLE","uptime_ms":...}`

**依赖库**：ArduinoJson（已装）

**验证结果**：✅ USB 串口正常刷 `boot` 和 `hb`；发命令有 `{"id":x,"ok":true}` 回应。Wi-Fi TCP 链路（hello 鉴权、ping、断线重连）代码已完成，**待台架实测**

## 六、当前卡点：泵不受 ESP32 控制（已定位为电平问题）

**已完成的对照测试**

| 测试 | 结果 | 结论 |
|---|---|---|
| 泵两根线直接接 5V 红/蓝轨 | 泵转 | 电源、面包板电源轨、泵都正常 |
| 驱动模块 SIG 用杜邦线碰 5V | 泵转 | 驱动模块、接线正常 |
| ESP32 GPIO25 → 模块 SIG，发 pump 命令 | 串口回 `ok:true`，泵不转 | **ESP32 3.3V 输出不足以触发「高电平触发」模块** |
| ESP32 GND ↔ 面包板蓝轨 | 已接 | 共地没问题 |

**结论**：软件/协议没问题；问题在 **3.3V → 5V 电平**。

**解决**：买 3.3V→5V 电平转换模块（BSS138 四路小板），或换 3.3V 兼容 / 带光耦的驱动模块。

**临时验证**：可用 LED + 1kΩ 电阻接 GPIO25 看灯，确认 GPIO 输出正常（当前手头暂无 LED/电阻）。
