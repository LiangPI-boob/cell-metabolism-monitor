## P3 背景与问题（从"生物痛点"改为"工程痛点"）
- 一句背景：细胞代谢（乳酸/葡萄糖）是细胞状态的前哨信号，动态监测有价值
- 三个工程难题（本页主角）：
  1. **测不久**：静态腔/细胞贴电极构型 → 扩散滞后、电极中毒，连续 12~72 h 不成立
  2. **测得漂**：酶电极衰减、参比漂移、基质变化 → 不校准则长时间定量失效
  3. **离不开人**：换液、校准、盯数据、出报告全靠人值守
- 引导句：谁能用低成本工程手段同时解决"久、准、无人值守"，谁就创造价值

## P5 我们的切入点（关键论证页，一句话）
- 一句话：**我们不是在芯片上集成了一个电极，而是开发了一套"膜下腔非侵入采样 + 闭环微循环 + 停流静测 + 在线自校准 + AIoT 数据链"的系统方案**
- 为什么这样能解决三大难题：
  - 膜下腔采样（芯片独有）→ 电极不碰细胞、循环防浓度梯度 → "测不久"变"测得久"
  - 闭环协议 + 周期标定 → 漂移可控 → "测得准"
  - 固件自动运行 + 上云 → "不用人守着"
- 呼应专业：这是传感 + 流控 + 数据问题，正是物联网专业的主场
- **关键对比**：不是"我们的电极比别人好"，而是"现有外置电极检测系统普遍缺少膜下腔非侵入采样和在线自校准闭环"——区别在系统集成，不在单个部件

## P6 系统设计——两件套（核心页，放结构图）
- 结构示意（培养芯片 + 检测模块闭环，见 芯片设计说明书 v3）：
  - 培养芯片：培养井（细胞静置）→ 多孔膜 → 小体积下腔
  - 检测模块：电极流道（商品化条状电极）+ 气泡阱 + 三通阀 + 标准液支路
  - 微型泵把"下腔 ↔ 检测模块"闭环慢循环（同成分培养基）
- 为什么拆两件套（一图讲清）：
  - 换电极 = 拔模块，不拆芯片不碰细胞
  - 校准 = 阀切标准液，在模块内完成
  - 模块先独立测漏调试，再联机 → 工程风险低

## P7 测量协议——"一个读数 = 一个校正浓度点"（核心页，放时序图）
- 四阶段循环（重复 12~72 h）：
  1. **常态循环**：泵低速跑，均质下腔、冲洗电极（防中毒/富集）
  2. **停流平衡**：停泵，膜上下短暂平衡
  3. **静测**：电极固定时序采样 → 1 个浓度点
  4. **在线校准**：每 6h 三通切标准液 → 更新灵敏度/截距 → 切回
- 结果：拼接出连续动态曲线；换液/加药自动打标
- 关键话术："连续"不是口号，是**协议在结构上保证的**

## P8 创新点总结（3 个卡片，每点：难题 → 做法 → 系统级差异）
**创新点①（系统级采样/流控）：膜下腔非侵入采样 + 闭环微循环 + 停流静测**
- 难题：静态腔/电极泡培养液测不久 | 做法：膜下小体积腔采样（芯片独有）+ 闭环循环 + 停流平衡静测
- 系统级差异 vs 别人：不是电极泡培养液（中毒快）、不是取样到外置池（扰动细胞）、不是 Seahorse（昂贵封闭）——我们用低成本结构件让"膜隔开细胞、电极独立循环"在系统层面成立

**创新点②（系统级测量协议）：停流静测 + 在线自校准闭环**
- 难题：长时间测得漂 | 做法：固件状态机自动循环 + 每 6 h 标准液在线标定 + 漂移补偿算法
- 系统级差异 vs 别人：几乎所有外置电极方案都是"实验前校准一次到底"——我们把标定做成系统的常态化自动环节，这是整套协议的闭环设计

**创新点③（系统级数据链）：端-云 AIoT 数据链**
- 难题：离不开人 | 做法：端侧采集 → MQTT 上云 → 远程实时曲线/告警 → 自动报告
- 系统级差异 vs 别人：现有电化学细胞代谢系统都是"仪器+上位机"单机形态——我们做成"传感—控制—云端"完整数据链

> 小字注明（非创新点但可复现性底气）：商品化电极、开源恒电位仪、结构外协

## P10 验证方案与可行性（核心页：V1 是答复"连续"的证据）
- **V1 无细胞 72h 长稳实验（重点讲）**：
  - 注入已知浓度标准液，自动跑 72h 完整协议
  - 指标 = 各采样点回收率；校准后单点误差 <15% 且无单调漂移
  - 含义：先用纯工程证据证明"12~72h 连续定量成立"，不依赖生物
- **V2 细胞验证（简版）**：一种细胞膜上静置培养，自动记录 12-24h 乳酸↑/葡萄糖↓；加药组 vs 对照组看趋势差异
- 可行性表（芯片/模块/固件/算法/AIoT 高，细胞中——生物侧仅配合）
- 原则：**先 V1 后 V2，逐级放行**

## 演讲备注要点（嘴上的话）
- P3/P5 是本场定位关键：把老师关心的"连续检测、工程化、AIoT"直接变成主线叙事
- P7 是技术核心页，务必讲清"循环→停流→静测→校准"，强调数值为建议初值、将由 V1 标定；主动讲采样口径（分钟级读点=准连续，类比 Seahorse），避免被追问"是不是隔一段时间测一次"
- 若被追问"这不还是测一下停一下"：答"读数间隔 ~10-15 min，远小于代谢变化的时间尺度（数分钟~数小时），足以无失真重建全程动态；这与安捷伦 Seahorse 的周期测量原理一致，且每次校准/读数都不扰动细胞"
- P10 是回应"连续是否成立"的证据页：先讲 V1（无细胞、纯工程），再讲 V2，节奏是"先证明能测久测准，再谈生物应用"
- 若老师追问商品化电极/原位检测：答"它们是低成本、可复现的工程特性，不是我们的创新主张"，把话题引回三个难题型创新点
