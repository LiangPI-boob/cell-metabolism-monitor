## 二、项目是什么 + 系统架构

做一台**自动养细胞 + 自动测代谢指标（葡萄糖/乳酸）**的准连续监测系统：

1. 细胞在 PC 0.4μm 多孔膜上静置培养
2. 代谢物透过膜扩散进「膜下小体积腔」（约 78 μL）
3. 下腔与独立检测模块用软管闭环循环
4. 停流静测（安培法）+ 每 6 小时在线自校准
5. 覆盖 12~72 小时无人值守

```
[手机/PC 浏览器] ⇄ Wi-Fi ⇄ [主机 NanoStat：ESP32-PICO-D4 + LMP91000]
                              ├ 电化学采集（ADC/C1/C2/DAC）
                              ├ 网页 :80 + WebSocket :81
                              ├ 实验调度状态机（本机执行，不依赖 PC）
                              └ SoftAP「NanoStatAP」+ TCP Server 192.168.4.1:3333
                                        ⇅ JSON 行协议（Wi-Fi，一行一个 JSON，\n 结尾，≤512 B）
                                 [从机 ESP32 流体控制板]
                                  ├ 循环泵 → GPIO25
                                  ├ 切换阀 → GPIO26
                                  └ 排废阀 → GPIO27
```

实验状态机：`IDLE → CIRCULATE → STOP_FLOW → MEASURE →（CALIBRATE）→ CIRCULATE`

## 五、首次上手 4 步

1. **补凭据**（不入库，缺失会 `#error`）：
   - `src/wifi_credentials.example.h` → `src/wifi_credentials.h`
   - `slave/slave_firmware/wifi_secrets.example.h` → `wifi_secrets.h`
   - `SLAVE_WIFI_PASS` 必须等于主机 `AP_PASSWORD`；`SLAVE_LINK_KEY` 两端必须一致
2. **烧主机**：

```powershell
$pio = "C:\Users\Liang\.platformio\penv\Scripts\pio.exe"
& $pio device list                                      # 先按 SN 确认 COM 口
& $pio run -e pico32 -t upload   --upload-port COM6
& $pio run -e pico32 -t uploadfs --upload-port COM6     # 仅在改了 data/ 网页时
```

3. **烧从机**：Arduino IDE 打开 `slave/slave_firmware/slave_firmware.ino`，装 ArduinoJson，选 COM5 上传
4. **验证链路（不动执行器）**：
   - `GET http://nanostat.local/netinfo` 看 `sta_connected` 与 `ap_clients`
   - 连 `ws://<主机IP>:81/` 读一帧状态，看 `"slave_link":"online"`

## 七、必知的坑（完整 11 条见 `项目进度总结.md` 第五节）

1. **串口日志停在 `BOOT: LMP init done` 不是崩溃** —— 是 CP210x 的 DTR/RTS 自动复位在反复拉 EN；判板子好坏看热点是否出现、LED 是否闪 15 次。
2. **`uploadfs` 会擦掉 SPIFFS 里的 `/calibration.JSON`** —— 日常不要跑；Wi-Fi 配置存在 NVS，不丢。
3. **国内网络装 ESP32 包 / PlatformIO 会卡** —— 用镜像或代理；移动工程后报错先删 `.pio`。
4. **不会误提交凭据** —— `.gitignore` 已覆盖 `src/wifi_credentials.h`、`slave/slave_firmware/wifi_secrets.h`、`data/secrets.json`、`.pio/`。
