# 细胞代谢监测系统设计说明书——膜下腔非侵入采样 + 闭环微循环 + 在线自校准（v3.0）

> 用途：交给老师/外协加工的系统方案说明
> 设计版本：v3.0（两件套解耦方案，取代 v2.0 "电极嵌入底座"三层夹心方案）
> 版本原因：评审要求芯片支撑 **12~72 h 连续检测**；v2.0 静态夹心下腔无法做到长时间连续定量，且电极更换/校准会扰动细胞、维护困难。v3.0 定位从"设计一个芯片"升级为**开发一套系统级方案**——培养芯片提供膜下腔采样结构（芯片独有），独立检测模块集成泵阀/电极/校准支路，二者软管连接闭环循环。
> 设计日期：2026 年 9 月

---

## 一、设计核心概念（一句话）

> **我们开发了一套基于"膜下腔非侵入采样 + 闭环微循环 + 停流静测 + 在线自校准"的细胞代谢准连续监测系统。** 细胞在膜上静置培养，代谢物经膜扩散进入膜下小体积腔，腔与独立检测模块软管连接闭环循环；系统按协议自动运行，全程不扰动细胞，可无人值守覆盖 12~72 h。
>
> **定位说明**：本方案的区别不在于"某一个部件是新的"，而在于**整套集成方案**——膜下腔采样结构（芯片独有）让电极不碰细胞、闭环循环防浓度梯度、停流静测保读数复现、周期校准控漂移、AIoT 数据链让远程监控成为可能。现有"外置电极检测"系统普遍缺少膜下腔这一非侵入采样结构，也没有在线自校准闭环。

### 为什么拆成两件套（与 v2 的本质差异）

- 检测环境（电极侧液体）与培养环境（细胞侧）**物理解耦**：细胞不受剪切与电极干扰，静置培养贴合常规习惯；
- 电极的**更换、校准、冲洗全部在检测模块完成，不碰细胞腔**——72 h 实验中途电极出问题可只换模块，实验不报废；
- 检测模块独立加工、独立调试、独立测漏后再与培养芯片联机 → 工程风险低、好排查。

### 与 v2.0 方案差异速览

| 项 | v2.0（旧） | v3.0（本版） |
|----|-----------|--------------|
| 电极位置 | 嵌入培养芯片底座，正对培养井 | **独立检测模块（电极流道），与下腔闭环** |
| 下腔 | 静态腔，被动扩散 | **小体积下腔 + 泵驱动闭环微循环（同成分培养基）** |
| 长时间连续 | 不成立（扩散滞后、电极富集/中毒、无校准） | **停流-静测 + 周期在线校准协议** |
| 校准/换电极 | 需拆芯片、扰细胞 | **模块内完成，不扰细胞** |
| 一体性 | 单芯片叙事 | 培养芯片 + 即插即用检测模块（工程系统定位） |

## 二、系统总体架构

```
【培养芯片】                           【检测模块】
┌────────────────────┐                ┌──────────────────────────┐
│ ① 上盖/培养井        │                │ ⑤ 电极流道（透明）         │
│    细胞膜上静置培养    │                │    · 商品化条状三电极插入槽  │
│    加药口 / 换液口     │                │    · 检测区露于流道底       │
├ ② 多孔膜 ───────────┤ 循环管 ◄─进出─► │ ⑥ 气泡阱                 │
│ ③ 下腔（小体积）      │                │ ⑦ 三通阀（循环/校准切换）    │
└──┬────入液口──┬─────┘                │ ⑧ 标准液瓶（校准支路）       │
   │   出液口    │                       └──────┬───────▲────────────┘
   └────────────┴──────────► ⑨ 微型泵 ◄───────┘       │
                          （低速闭环循环同成分培养基）     （校准切回/排废隔离阀）
```

- ⑨ 微泵常态驱动"下腔 ↔ 检测模块"闭环慢循环：均质下腔液体、冲洗电极表面；
- ⑦ 三通阀周期切入标准液 → 检测模块内完成在线标定 → 排废/隔离，**标准液不回流细胞腔**；
- 循环介质 = **与培养液同成分的培养基（无细胞）**，避免"营养渗漏"，维持培养环境稳定。

## 三、培养芯片设计参数（含膜与下腔）

### 1. 上盖/培养井层
- 材料：透明 PDMS 或亚克力（便于显微镜观察）；
- 培养井：圆形，直径约 8~10 mm，深约 3~5 mm；井口敞开便于接种；
- 侧壁开加药口 / 换液口（直径 1~2 mm 接软管，人工操作，由系统打标事件）。

### 2. 多孔膜
- 材料：聚碳酸酯（PC）商品化细胞培养膜；
- 孔径：约 0.4~3 μm（拦细胞 ≥10 μm、放行乳酸/葡萄糖小分子）；
- 功能：细胞贴膜上静置生长；代谢物经膜扩散进入下腔；
- 固定：可压合/卡紧固定，可拆卸更换。

### 3. 下腔（膜下方，核心新增）
- 作用：紧贴膜下的收集腔，代谢物经膜扩散于此，并与检测模块闭环循环；
- 体积：**尽可能小**（建议数十 μL~百 μL），小体积→跨膜平衡快、读数更贴近培养液浓度；
- 端口：进液口、出液口各一（φ1~2 mm，接软管连检测模块）；
- 腔深：建议 ≤0.5~1 mm，减少膜-检测回路之间的死体积与扩散滞后。

### 4. 培养芯片材料与固定
- 三层（上盖/膜/下腔板）可拆装：压合固定即可（密封与长期可靠性属于后续工程优化，v3.0 以**方法可行性验证**为目标，暂不细化）；
- 下腔板与检测模块之间用软管快插连接，整体可拆卸灭菌。

## 四、检测模块设计参数

### 5. 电极流道（透明、可插拔）
- 材质：透明亚克力/PDMS + 盖片；
- 流道：直线或微蛇形，体积数 μL~数十 μL，高度约 0.5~1 mm；
- 电极槽：自侧方水平开槽，插入**商品化条状三电极**（工作/参比/对电极一体）；
  - 检测区恰好暴露于流道底、对准流道中心；
  - 槽口硅胶垫/O 圈密封防漏；
  - 电极端子外伸，接恒电位仪（NanoStat/自制）；
- 可整体快拆 → 换电极或换指标只需替换本模块。

### 6. 泵阀与流路
- 微型泵：低速闭环循环（建议先试 50~100 μL/min），静音、可程控启停；
- 三通阀：常态"培养回路 ↔ 检测模块循环"；校准状态切换至标准液支路；
- 校准支路：标准液瓶 + 排废/隔离阀 → 校准液在模块内流动后排出或隔离，**不回细胞腔**；
- 气泡阱：置于泵前，拦截气泡，保证 72 h 运行稳定；
- 温/湿度：如实验不在培养箱内，模块与芯片置于 37 ℃ 加热/保湿装置中。

## 五、测量协议与时序设计

| 阶段 | 泵/阀动作 | 目的 | 建议时长/参数 |
|------|-----------|------|--------------|
| ① 常态循环 | 泵开（低速） | 均质下腔、冲洗电极表面、带走产物 | 数分钟~数十分钟一档；50~100 μL/min |
| ② 停流平衡 | 泵停 | 膜上下跨膜短暂平衡 | 5~15 min（视下腔体积/膜面积，待 V1 标定） |
| ③ 静测 | 泵停、阀不变 | 电极固定时序采样 → 得 1 个浓度点 | 30~60 s 短窗安培法 |
| ④ 在线校准 | 三通切标准液 → 读数 → 切回循环 | 更新灵敏度/截距，补偿漂移 | 每 6 h 一次，3~5 min/次 |
| ⑤ 事件标注 | 人工/预留口执行 | 换液、加药自动打标 | 任意时刻，24 h 换液一次为生物侧常规 |

> 一个"循环-平衡-静测"周期 ≈ 产出 1 个校正后浓度点；通过缩小下腔体积、增大膜面积，目标把周期压到约 **10~15 min 一个点**，12~72 h 重复拼接即得覆盖全程的**准连续动态曲线**。数值均为**建议初值，需经 V1 标定实验优化**。
>
> **口径说明**：读数为**分钟级周期采样**（与 Seahorse 代谢仪一致），而非逐秒无间断记录；细胞代谢动力学时间尺度为数分钟~数小时，分钟级采样足以无失真重建全程动态，因此表述统一为**"准连续 / 全程连续动态监测"**。如需逐秒曲线（汇报演示），可切换"恒定循环 + 高占空比记录"模式，代价是更依赖泵流量稳定、电极占空比更高。

## 六、与 v2.0 的差异对照（供评审汇报用）

| 评审关注 | v2.0 回应 | v3.0 回应 |
|---------|-----------|-----------|
| 连续检测能否成立 | 静态夹心，扩散滞后+电极中毒，无法长时间连续 | **闭环循环 + 停流静测 + 周期校准**，结构上支撑 12~72 h |
| 电极维护 | 拆芯片换电极，扰细胞 | **独立检测模块即插即换，不扰细胞** |
| 长时定量可信 | 实验前一次性标定，误差累积 | **在线自校准 + 漂移补偿算法** |
| 生物扰动 | 检测与培养空间共存 | **物理解耦，细胞静置**，贴近常规培养 |
| 专业优势（物联网） | 创新点叙事偏生物 | 固件状态机、泵阀时序、标定算法、AIoT 数据链成为主体 |
